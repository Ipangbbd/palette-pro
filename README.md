Built with **HTML, CSS, and JavaScript**, fully responsive, and open source.

## ✨ Features

- ⚡ **Instant Palette Generation** – one click, endless combinations  
- 📋 **Copy to Clipboard** – copy HEX codes instantly  
- 📂 **Export Options** – CSS, SCSS, JSON formats  
- 📱 **Responsive Design** – works smoothly on all devices  
- 📨 **Feedback Form** – powered by Web3Forms  
- 🆓 **Free & Open Source** – no hidden limits

## 🚀 Getting Started

1. Clone the repository:  
   ```bash
   git clone https://github.com/Ipangbbd/palette-pro.git
````

2. Open `index.html` in your browser
3. Click **Generate Palette** and explore

---

## 🎮 Usage

* 🎨 Generate palettes instantly with the button
* 📋 Copy HEX values with one click
* 💾 Export palettes to CSS, SCSS, or JSON
* ⭐ Submit feedback via the built-in rating form
